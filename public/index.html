The platform

A sovereign workbench for the most personal data you own.

Millions of people have a genome export and almost no trustworthy local tooling. SovereignDNA turns that file into a private, agent-driven workbench — computation stays on your device by default.

Local-first

A Tauri + Rust desktop app with a local SQLite store. Your raw genome is imported once and never uploaded.

Skills runtime

Signed, sandboxed analysis skills with evidence tiers and citations — health-risk, pharmacogenomics, traits, carrier status.

Research agents

Personal agents that watch PubMed and ClinVar for your variants and rerun scores when reference data changes.

Privacy ledger

Every outbound action is logged: which public rsIDs or reference queries left the device, where they went, and why.

Live backend demo · Phase 1.1 shipped

Streaming ingestion, in real time.

Whole-genome files run 1–100+ GB. The old importer loaded the entire file into RAM. We rebuilt it as a constant-memory stream: file → parser → SQLite, in bounded batches. Run it below — the payload streams live from this site's Cloudflare Worker.

    fn parse_streaming(
        &self,

        sink:   &mut dyn SnpSink,   // each variant emitted as it is read
    ) -> Result<ParseSummary>;
